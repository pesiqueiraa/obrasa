# Segurança

Achou uma falha de segurança no oBrasa (site, banco ou pipelines)? Não abra uma issue
pública. Use o botão **Report a vulnerability** na aba **Security** deste repositório:
o relato fica privado entre você e quem mantém o projeto.

Para um número errado no site, use a página "Reportar erro", no rodapé do site.
